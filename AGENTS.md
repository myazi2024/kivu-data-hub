- Keep loading-image settings in `app_appearance_config`, applying them once at the root and styling existing loading indicators through shared CSS; this avoids per-indicator network calls across lazy-loaded screens.
- The home land-district map is built from the bundled territories GeoJSON: only areas whose name matches exactly one land district of the same province are coloured, others stay greyed; borders are never approximated because no verified district geometry is bundled.
